Dynalist Image Markdown

Turn an image link into Markdown you can paste directly into Dynalist.

Method 1: Use an image that already has a link

This is the easiest method. Use it whenever the image is already online.

  1. Find the image online.
  2. Right-click the image (or two-finger tap on a trackpad).
  3. Select Copy image address (not Copy link).
  4. Paste the image address into the box below.

Method 2: Adding a screenshot or image without a link

Use this method only if you have an image saved on your computer or copied to your clipboard and cannot copy an image address from a website.

  1. Open the class Formative image-link assignment.
  2. Open a private comment to the teacher.
  3. Paste your image into the private comment using Ctrl + V.
  4. Right-click the image (or two-finger tap on a trackpad) and select Copy image address.
  5. Return here and paste the copied address into the Image URL box below.
